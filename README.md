# Padel Tournament Manager V1.4

Mobile-first веб-приложение для управления турнирами по паделу.

## Возможности
- Индивидуальный Americano с ротацией партнёров.
- Турниры фиксированных пар.
- Фиксированная сумма 16–32 очка на матч.
- Автоматическая жеребьёвка и распределение по кортам.
- Live-ввод результатов и автоматический рейтинг.
- Контроль повторов партнёров/соперников.
- История турниров и статистика игроков.
- Экспорт/импорт JSON.
- Offline cache через service worker.

Данные V1.4 хранятся локально в браузере (localStorage). Серверной синхронизации и аккаунтов пока нет.
